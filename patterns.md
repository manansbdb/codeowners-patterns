# Patterns / Padrões

## English
- Last matching pattern wins.
- Prefer team @mentions over individuals for bus-factor resilience.
- Keep paths aligned with ownership of deployables.
- Protect the default branch and require CODEOWNER review on sensitive paths.

## Português
- O último padrão que faz match ganha.
- Prefira @mentions de equipas em vez de indivíduos (bus factor).
- Alinhe paths com ownership dos deployables.
- Proteja a branch default e exija review de CODEOWNER em paths sensíveis.
